# 调试模式（适配工具）

给适配新游戏用的引擎内工具（补丁 0053，所有 profile 通用）：加速、暂停与逐帧、强制快进、按句回退、存取状态、跳到任意剧本标签、一键解锁。默认关闭，不影响正常游玩。

## 打开

- 宿主设置 `debugMode: true`（写入该游戏 `userconfig.toml` 的 `[CommonSettings] DebugMode = true`），或直接改这个键。profile 带 `GameFeature::DebugMenu` 时也会打开。
- 进游戏后画面左上角有一行状态：运行／暂停、速度、是否强制快进、主线程所在剧本与对白行号（最近的检查点）、可回退的句数。
- **三根手指同时按屏幕**打开调试菜单（键盘 Alt+D、手柄 RB+Y 仍可用）。三指手势本身不会被游戏当成点击；手指落在调试窗口上时游戏也收不到。
- 菜单里的「适配工具」标签页（停靠模式下是单独的「适配工具」窗口）就是本工具；顶部可切换中文／English，下面一行显示上一次操作的结果。窗口不会超过屏幕高度，内容多时拖右侧滚动条。

## 功能

| 区块 | 功能 |
| --- | --- |
| 速度 | 逻辑速度 x1–x64（每帧跑多次逻辑更新，文字与动画一起加速；一帧的输入只在第一次更新里生效，菜单不会被同一次点击触发多次）；暂停；暂停时单步 1 帧／60 帧 |
| | 「跳过当前视频」：当作视频已经播完，等视频的剧本继续 |
| | 「强制快进」：打开引擎的快进并关掉「只跳已读」（关闭强制快进时恢复原设置），未读文字也跳；不循环的视频直接跳过。选项、需要玩家操作的画面仍会停下 |
| 回退 | 每到一句新台词（剧本的检查点）自动快照，默认保留 300 句（10–5000 可调）；「退 1 句」「退 10 句」，或在列表里点任意一句直接回去。回到选项那一句时选项会重新出现，可以重选 |
| 保存的状态 | 把当前这一句存成命名条目（不填名称就用剧本名和行号），跨启动保留（存档目录下的 `debug-states.bin`）；可在标题画面直接读取 |
| 跳转 | 选剧本文件、标签号、脚本缓冲区与线程（-1 = 主线程，默认是主线程当前所在的剧本与缓冲区），把线程直接跳到该标签，可选清空调用栈；显示主线程位置与该剧本的标签数。「从头重开当前剧本」= 跳到当前剧本的标签 0 |
| 进度 | 一键解锁 CG、音乐、TIPS；立即写入存档 |

原有的调试菜单（「Debug Editer」里的 ScrWork／FlagWork 编辑器、Objects、Script Debugger）照常可用，配合保存的状态可以随意切换进度。

## 适配时的常用流程

1. 新游戏 → 速度 x64 + 强制快进，一路跑到出问题的地方（卡住、画面不对、报错）；停下后关掉强制快进、调回 x1。
2. 用「退 10 句」「退 1 句」或列表回到出问题之前，逐句复现；需要反复试的地方先「保存当前状态」，改完代码重新安装后从标题直接读取。
3. 想直接看某一段剧本时用「跳转」；剧本不进入某个分支时，用「Debug Editer」改标志或变量后再跳。
4. 视频相关的问题：「跳过当前视频」排除视频本身，或对照 `SF_MOVIEPLAY` 等标志看剧本在等什么。

## 实现要点

- 快照内容：`ScrWork`、`FlagWork`、完整的 VM 线程池（`Vm::SaveVmState`／`RestoreVmState`，链表指针按下标保存）、各缓冲区载入的剧本号、剧本用 `LoadPic` 载入的系统贴图（`SpriteLoader` 记下档案与文件号）、SGHD 的手机状态。
- 快照在检查点指令执行完时拍，并把线程指回这条指令的开头：恢复后这条指令重新执行，台词重新显示、选项重新建立。
- 恢复时停掉正在播的视频，清空对话框与选项，重载不一致的剧本与系统贴图，再按工作区重新同步背景、立绘与 BGM。不恢复音效与正在播放的语音。
- `debug-states.bin` 的格式（`TDS2`）依赖 `Sc3VmThread` 的大小：引擎版本变化导致大小不同时整份忽略，不会读错。
- 验证：MuMu 模拟器（Android 15，不是真机）上用 `sg-pc`（Steam 原文件＋2018 汉化）与 `mo6tw-pc-zhs` 实测以上功能。真机未测。
